# Meus sites favoritos — Agenda 12

Página web desenvolvida para a atividade de Desenvolvimento de Sistemas I.

## Como executar localmente
1. Baixe ou clone este repositório.
2. Mantenha o arquivo `index.html` e a pasta `imagens` na mesma estrutura.
3. Abra o arquivo `index.html` em um navegador.

## Sites escolhidos
- [YouTube](https://www.youtube.com)
- [GitHub](https://github.com)
- [Crunchyroll](https://www.crunchyroll.com)
- [Spotify](https://open.spotify.com)
- [Minecraft](https://www.minecraft.net)

## Estrutura
- `index.html`: estrutura HTML e estilos CSS da página.
- `imagens/`: imagens SVG locais utilizadas nos cartões.

## Publicar com GitHub Pages
1. Acesse **Settings** neste repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)**.
5. Clique em **Save** e aguarde a publicação.
